NeuroRun is a web application for runners (French-speaking audience) that offers a personal dashboard, race performance insights, and a conversational coach to help users structure training, track progress, and prepare goals from 5K to marathon.

Connecting Strava is optional. A user must explicitly link their Strava account through Strava’s OAuth flow before any API access. Running activity data retrieved via the API is used only for that authenticated user and is never shown to other users of the app or sold or shared with third parties for advertising. Uses are: aggregated statistics (volume, pace trends, etc.) on the user’s dashboard; forecasts and analysis based on that user’s own running history; and activity summaries to personalize coach replies. NeuroRun complements Strava and does not replace the Strava platform.

We comply with the Strava API Agreement: consent before access; a published privacy policy; end-user support contact; users can revoke access in their Strava account and request deletion of their data in our app; Strava API Brand Guidelines where Strava data is shown; HTTPS and secure server-side token handling. Strava data is used to display information to the authorized user and to contextualize coach responses (inference only). We do not use Strava data to train or fine-tune machine learning or AI models.

### Variante française (si tu préfères répondre en français)

NeuroRun est une application web d’accompagnement à la course à pied (public francophone) : tableau de bord personnel, analyses de performance et coach conversationnel pour structurer l’entraînement, suivre la progression et préparer des objectifs du 5 km au marathon.

La connexion Strava est optionnelle. L’utilisateur doit associer explicitement son compte via le flux OAuth Strava avant tout accès API. Les données d’activités course obtenues via l’API ne servent que l’utilisateur authentifié : elles ne sont jamais affichées à d’autres utilisateurs ni cédées à des tiers à des fins publicitaires. Elles permettent d’afficher des statistiques agrégées sur le tableau de bord, des prévisions fondées sur son historique personnel, et de résumer des activités pour personnaliser les réponses du coach. NeuroRun est un complément à Strava, pas un substitut à la plateforme.

Conformément au Strava API Agreement : consentement préalable, politique de confidentialité, contact support, révocation possible depuis le compte Strava et suppression des données côté application sur demande, respect des Strava API Brand Guidelines là où des données Strava apparaissent, HTTPS et jetons gérés côté serveur. Les données Strava servent à l’affichage pour l’utilisateur autorisé et à contextualiser le coach (inférence uniquement), sans entraînement ni fine-tuning de modèles d’IA ou d’apprentissage automatique sur ces données.
